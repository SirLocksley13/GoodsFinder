# Publishing Checklist

## Final files

- `release/GoodsFinder_v1.0.0.zip` — upload as the mod file
- `media/GoodsFinder_Modio_Logo_1280x720.png` — main Mod.io logo
- `media/GoodsFinder_How_To_Use_1280x720.png` — optional gallery image
- `docs/MODIO_UPLOAD_TEXT.md` — copy the profile fields and description
- `CHANGELOG.md` — GitHub and release notes
- `CHECKSUMS.txt` — verify files before uploading

## Before uploading

1. Remove every older Goods Finder test build.
2. Install only `GoodsFinder_v1.0.0.zip`.
3. Confirm `[Goods Finder 1.0.0] Lua loaded`.
4. Test normal browsing and consecutive uses.
5. Confirm no save question during normal Goods Finder use.
6. Confirm deliberate island addition still triggers the normal save question.
7. Upload the exact final ZIP without repacking it.
