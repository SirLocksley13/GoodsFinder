# Goods Finder for Anno 117

Goods Finder is a savegame-compatible quality-of-life mod for **Anno 117: Pax Romana**.

Hover a product in a warehouse and press **Ctrl+Alt+G**. The mod opens the vanilla goods list, focuses the product, and displays its stock across all owned islands in the current province.

## Release

The public mod is located in `goods-finder/`.

The ready-to-upload Mod.io package is located in `release/GoodsFinder_v1.0.0.zip`.

## Highlights

- Province-wide island stock from a warehouse
- Fully interactive vanilla goods list
- Safe originally-empty trade-route doorway row
- Automatic cleanup of temporary product selections
- Existing cargo instructions remain protected
- No Ship Finder dependency
- Existing savegames supported

## Important behavior

If the player makes a genuine route change, such as adding an island, Anno 117 correctly displays its normal **Save changes?** confirmation. Goods Finder does not silently undo deliberate route edits.
